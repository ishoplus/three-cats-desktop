# 三貓日和 桌面版

讓[三貓日和](https://cats.xi-za.com)的貓在你的電腦桌面上走來走去。到 [Releases](https://github.com/ishoplus/three-cats-desktop/releases/latest) 下載：

- Mac（Apple 晶片／Intel 都可以）：`ThreeCats-mac.zip`
- Windows：`ThreeCats-win-x64.zip`（ARM 電腦用 `ThreeCats-win-arm64.zip`）

解壓縮後打開就好。Windows 第一次開會出現「不明發行者」，按「其他資訊」→「仍要執行」。
